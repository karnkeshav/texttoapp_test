## Overview

This PR implements comprehensive performance and reliability improvements across the text-to-app AI infrastructure with a focus on reducing input token bloat and adding intelligent truncation detection.

## Changes Summary

### 1. Truncation Detection System (NEW)
- Created truncationDetector.js module with isStreamTruncated() function
- Detects multiple truncation patterns: unclosed code fences, missing HTML tags, incomplete code blocks, mid-expression line endings
- Integrated into all 4 AI model pools

### 2. Model Pool Optimization
- All 4 pools reordered by token capacity (highest ceiling first)
- Added tier-based model selection (build vs chat tier)
- Truncation checks with appropriate fallback strategies

### 3. 3-Attempt Self-Healing Quality Pass (codeQuality.js)
- Attempt 1: Targeted file-by-file repair with truncation detection
- Attempt 2: Full regeneration with compact prompt
- Attempt 3: Senior developer diagnosis
- Audit 4: Final validation before deployment

### 4. System Instruction Modularization (antigravity.js)
- Split SYSTEM_INSTRUCTION into 3 modular constants (CORE, DESIGN, SANITY)
- Created buildSystemPrompt(mode) for mode-specific prompts
- Added SCOPE RULE: Implement core features only

### 5. Tier Parameter Threading
- Tier parameter flows through entire model selection chain
- Enables dynamic model selection based on request type
- Build tier: 70B+ models; Chat tier: 8B/12B models

### 6. Truncation Error Handling
- Detects truncated responses from Antigravity
- Escalates to Gemini pool (higher token ceiling)
- TRUNCATED_OUTPUT error code prevents circuit breaker trips

### 7. Token Reduction (PRIMARY FIX)
Before: System (~3.8k) + enrichedNotes (~3k) + History with code (~45k) = 52,000 tokens
After: System (~3.8k) + enrichedNotes (~2-3k) + Stripped history (~1.2k) = 6,500-8,000 tokens

Solution: stripCodeFromHistory() function removes code blocks and increases history window from 3 to 6 turns (80% token reduction).

### 8. Chat.js Improvements
- Added tier parameter to all streamChat calls
- Optimized dry-run fixPrompt
- Added NEEDS_REGENERATION error handling

### 9. Stack Advisor Enhancements
- Added truncation fence detection in runDryCheck
